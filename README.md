# Bidly — Online Auction Marketplace

A polished, responsive online bidding marketplace frontend built with HTML, CSS and JavaScript.

## Features
- Live auction listings with countdown timers
- Search and category filtering
- Sort by ending time and price
- Browser-based watchlist
- Interactive bidding modal
- Demo bid persistence with localStorage
- Responsive mobile navigation
- Newsletter interaction
- Marketplace-focused responsive design

## Current version
This repository is a frontend demo. Real authentication, payments and server-side auction transactions are not implemented yet.

## Production roadmap
The existing UI is ready to connect to a PHP/MySQL backend for:
- User registration and login
- Password hashing and verification
- Secure PHP sessions
- Server-side bid validation
- Atomic bid transactions
- Auction closing and winner selection
- Seller verification
- Payments and order management
- Admin dashboard

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## GitHub Pages
From the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the default branch and the root folder.
